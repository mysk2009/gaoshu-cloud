# 云端一键收作业（Render 免费 Web + Neon 免费 Postgres）· 上线与使用说明

一句话：学生电脑上照常做题，做题记录一键交到云上；老师和教授**用手机、平板、办公室电脑、任何网络**都能看到全班情况，
**老师不用注册任何平台，不需要任何人开着电脑，不需要买服务器，不需要备案，不花钱**。

---

## 一、三步上线（一次性，约 20 分钟）

### 第 1 步 · 建数据库（Neon，免卡）

1. 打开 https://neon.tech ，用 GitHub 或邮箱注册（**不需要信用卡**）
2. 新建一个项目（Region 选 `Singapore` 或 `AWS Asia Pacific (Singapore)`，离国内最近）
3. 复制它给的连接串，形如：
   `postgresql://用户名:口令@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
   （**必须带 `?sslmode=require`**）

### 第 2 步 · 部署服务（Render，免卡）

1. 打开 https://render.com ，用 GitHub 登录
2. 授权 Render 读取本仓库 `gaoshu-recommender`
3. New → **Blueprint** → 选这个仓库 → Render 会自动读到根目录的 `render.yaml`，点 Apply
4. 在 Environment 里填三个值：
   - `CLOUD_DB_URL` = 第 1 步的 Neon 连接串
   - `CLOUD_ADMIN_TOKEN` / `CLOUD_SECRET_KEY` 由 Render 自动生成，不用管
5. 等 2–3 分钟部署完成，打开 `https://<你的服务名>.onrender.com/api/health`，看到
   `{"ok":true,"db":"up","backend":"postgres"}` 就是上线成功

### 第 3 步 · 建第一个班（可选）

浏览器打开 `https://<你的服务名>.onrender.com/teacher`，点「第一次用？30 秒建一个班」，填写班级码、班级名、
老师姓名和管理口令即可。老师也可以自己建班；管理员部署一次，老师不用注册 Neon 或 Render。

| 项目 | 免费额度 | 对本项目意味着什么 |
|---|---|---|

## 三、老师每天怎么用（零注册）

老师只需要三样东西：**网址 + 班级码 + 管理口令**。

1. 手机或电脑打开 `https://<你的服务名>.onrender.com/teacher`（第一次等 30–60 秒）
2. 输入班级码和管理口令，点「进班」
3. 第一次用的老师点「第一次用？30 秒建一个班」，建好后页面会生成一张发给学生的小卡片：
   网址、班级码、学生班级口令。三个都能单独复制，也能整段复制到班级群
4. 进班后直接看人话结论：
   - 最上面告诉老师已交多少、谁还没交
   - 下一步直接建议先讲哪几道题、再让谁补练习
   - 每个人的表格里有「建议」，讲评清单里有「为什么讲」
   - 点「复制名单」可把未交学生发到群里
5. 点「导出 Excel」仍会得到 4 页表：班级概况、逐人明细、未交名单、讲评清单

教授或其他老师要看自己班，只需使用各自的班级码和管理口令，**都不需要注册任何平台**。

## 四、学生怎么交（3 步）

1. 打开题库程序 → 设置页 → 「提交给老师」
2. 填**班级码**和**学号、姓名**（第一次要填，填错会提示「学号不在本班名单」或「姓名与该学号登记的不一致」）
3. 点「一键提交我的学习记录」→ 显示「成功 N 条 · 重复 M 条」就成功了

> 同一个学号只能绑一台电脑。换电脑要老师登录 `/teacher` 后解绑（底层接口是 `/api/admin/roster/unbind`）。
> 断网、云端休眠、老师电脑关着，都**不影响学生做题**——记录先存在本机，联网后再交。

## 五、出问题对照表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 第一次打开网址转圈 30–60 秒 | 免费实例在休眠 | 等它醒，之后正常 |
| 「班级口令不正确」 | 班级码对、口令错 | 找老师要正确的班级口令 |
| 「学号不在本班名单」 | 名单里没这个学号，或学号打错（全角/半角） | 找老师导名单/核对学号 |
| 「姓名与该学号登记的不一致（登记：张\*三）」 | 姓名和名单不一致 | 按打码提示核对，别问系统要全名 |
| 「该学号已绑定其他设备」 | 同一学号已经绑了另一台电脑 | 找老师解绑 |
| 「这台设备已在班级 XXX 提交过」 | 一台电脑只能交一个班 | 换班找老师解绑，或换一台电脑 |
| 「尝试次数过多，请 10 分钟后再试」 | 同一台电脑 10 分钟内错了 5 次**且这次还是错的** | 填对学号姓名就不会被挡；真被挡就等 10 分钟 |
| 看板显示「云端还没收到任何数据」 | 学生还没提交 | 让学生点「一键提交」 |

## 六、边界（必须让老师知道）

1. **云端只存"交上来的记录"，不存题库**。题库、推荐逻辑、PDF 全在学生自己的电脑上。
   所以云端看到的是"谁做了多少题、对错、错在哪类"，看不到题目原文和解答。
2. 名单（学号+姓名）会上传到云端数据库，仅用于核对身份和算"未交名单"。不需要时可在 Neon 里一键清空该表。
3. **一班一个管理口令，班级之间相互隔离**：老师登录后只能查看、导名单、解绑和导出自己 token 绑定的班级。
   把某个班的管理口令给别人，只会开放这一个班，不会看到其他班。学生班级口令和管理口令是两套不同口令。
4. **两个"总作答"数口径不同**：学生端提交后提示的"总收到 N 条"是**全班累计上报条数**（含已解绑设备）；
   看板顶部"总作答"只统计**当前已绑定学生**的记录。有解绑操作时两者会差几条，属正常。
5. 免费实例是**单实例**：登录失败限流记在进程内存里，重启服务后计数清零；**重启后老师要重新输一次口令**
   （登录凭证 12 小时有效，重启会作废）。对本项目够用。
6. 想下线：Render 里 Suspend 服务 + Neon 里删项目，**一分钟内彻底停掉，不留费用**。

## 七、本地自测（不联网验证这套云端代码）

```bash
# 1. 用 SQLite 后端起服务（端口 8099）
CLOUD_DB_URL="sqlite:///cloud/data/local.db" \
CLOUD_ADMIN_TOKEN="dev-admin" \
CLOUD_SECRET_KEY="dev-secret" \
python cloud/run_local.py

# 2. 健康检查
curl http://127.0.0.1:8099/api/health

# 3. 老师自助建班（无需注册）
curl -X POST http://127.0.0.1:8099/api/teacher/create \
  -H "Content-Type: application/json" \
  -d '{"class_code":"F34F05","class_name":"高数A班","teacher_name":"王老师","admin_secret":"abc12345"}'

# 4. 打开老师入口
#    http://127.0.0.1:8099/teacher
```
